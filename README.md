Portfolio Website
A simple and responsive personal portfolio website built using HTML and CSS. The website contains sections for personal information, skills, projects, education, certified courses, contact details, and footer navigation.

📌 Features
Responsive portfolio design

Header with navigation menu

Personal introduction / hero section

About Me section

Skills section

Projects showcase

Education details

Certified courses section

Contact information

Footer with navigation and contact details

Mobile responsive layout

Uses local images from the asset folder

🛠️ Technologies Used
HTML5

CSS3

CSS Grid

Responsive Media Queries

🚀 How to Run
Download or clone this project.

Make sure the folder structure is correct:

asset/
    mypic.jpg
    project1.jpg
    project2.jpg
    project3.jpg

Open index.html in any web browser.

No server or additional installation is required.

🖼️ Images
The website uses the following local images:

mypic.jpg — Profile image

project1.jpg — Project 1

project2.jpg — Project 2

project3.jpg — Project 3

Place all images inside the asset folder.

📱 Responsive Design
The website includes a CSS media query for screens smaller than 700px.

On mobile devices:

Sections become single-column layouts

Skills become two-column layouts

Projects stack vertically

Education and contact information stack vertically

Footer sections stack vertically

✏️ Customization
You can replace the sample information in index.html with your own details.

For example:

<div class="name">Your Name</div>
<div class="field">Your Field Name</div>

Replace it with:

<div class="name">John Doe</div>
<div class="field">Full Stack Developer</div>

You can also update your:

Email

Mobile number

Education

Courses

Skills

Project images

About Me description

LinkedIn information
